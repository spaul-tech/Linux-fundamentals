# 🐚 Bash Scripting

Bash scripting is the process of writing commands in a file (`.sh`) to automate tasks in Linux. It helps reduce manual work and improve efficiency.

## 📌 Topics Covered

- Variables
- User Input
- Conditional Statements (`if`, `elif`, `else`)
- Loops (`for`, `while`)
- Functions
- Command-Line Arguments
- File Operations
- Exit Status
- Basic Automation

### To create a bash file, type the below command in terminal:
```bash
nano script.sh
```

## 🧪 Examples

### Print a Message
```bash
#!/bin/bash

echo "Hello, World!"
```

Run the script:

```bash
chmod +x script.sh
./script.sh
```   

## 📝 Summary

- Bash scripts automate repetitive tasks.
- Scripts are saved with the `.sh` extension.
- Use `chmod +x` to make a script executable.
- Execute a script using `./script.sh` or `bash script.sh`.
