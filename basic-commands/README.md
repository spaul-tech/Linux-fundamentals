# `cd`

Changes the current directory.

| Command | Description |
|---------|-------------|
| `cd ..` | Go to the parent directory |
| `cd ~` | Go to the home directory |
| `cd /` | Go to the root directory |


# `pwd`

Shows current folder

# `ls`

Lists files/folders

|Command|Description|
|-|-|
|`ls -l`|Gives detailed list|
|`ls -a`|Shows hidden files|

# `mkdir`

Makes new directory
