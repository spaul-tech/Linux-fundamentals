# Basic Linux Commands

*This repository documents the Linux commands I have learned and practiced while building my cybersecurity foundation. It serves as my personal reference and a record of my hands-on learning. New commands and examples will be added as I continue my cybersecurity journey.*

## Linux Commands Reference

| Command | Description | Example |
|---------|-------------|---------|
| `pwd` | Print current working directory | `pwd` |
| `ls` | List files and directories | `ls` |
| `ls -l` | Long listing format | `ls -l` |
| `ls -a` | Show hidden files | `ls -a` |
| `ls -la` | Long listing with hidden files | `ls -la` |
| `cd folder` | Change directory | `cd Documents` |
| `cd ..` | Move to parent directory | `cd ..` |
| `cd ~` | Go to home directory | `cd ~` |
| `cd /` | Go to root directory | `cd /` |
| `mkdir` | Create a new directory | `mkdir project` |
| `rmdir` | Remove an empty directory | `rmdir project` |
| `touch` | Create an empty file | `touch notes.txt` |
| `nano` | Create or edit a text file | `nano test.txt` |
| `cp` | Copy files or directories | `cp file.txt backup.txt` |
| `mv` | Move or rename files | `mv old.txt new.txt` |
| `rm` | Remove a file | `rm file.txt` |
| `rm -r` | Remove a directory recursively | `rm -r folder` |
| `rm -rf` | Force remove recursively | `rm -rf folder` |
| `cat` | Display file contents | `cat file.txt` |
| `head` | Display first 10 lines | `head file.txt` |
| `tail` | Display last 10 lines | `tail file.txt` |
| `less` | View file page by page | `less file.txt` |
| `find` | Search for files/directories | `find . -name "file.txt"` |
| `grep` | Search text in files | `grep "hello" file.txt` |
| `chmod` | Change file permissions | `chmod +x script.sh` |
| `chown` | Change file ownership | `sudo chown user:user file.txt` |
| `whoami` | Display current user | `whoami` |
| `hostname` | Display system hostname | `hostname` |
| `uname -a` | Display system information | `uname -a` |
| `df -h` | Show disk usage | `df -h` |
| `du -sh` | Show directory size | `du -sh Downloads` |
| `ps` | List running processes | `ps aux` |
| `top` | Display running processes in real time | `top` |
| `kill` | Terminate a process | `kill PID` |
| `ping` | Test network connectivity | `ping google.com` |
| `ip a` | Show IP address information | `ip a` |
| `ip route` | Display routing table | `ip route` |
| `man` | Open the manual page | `man ls` |
| `--help` | Show command help | `ls --help` |
