# 🌐 Networking

Linux provides powerful networking tools for checking connectivity, viewing network information, and troubleshooting network-related issues.

## 📌 Common Commands

| Command | Description |
|---------|-------------|
| `ip a` | Displays IP addresses and network interfaces. |
| `ping` | Tests connectivity to a host. |
| `ss` | Shows active network connections and listening ports. |
| `netstat` | Displays network statistics (legacy). |
| `traceroute` | Shows the path packets take to a destination. |
| `nslookup` | Queries DNS records. |
| `dig` | Retrieves detailed DNS information. |
| `curl` | Transfers data from or to a server. |
| `wget` | Downloads files from the internet. |

## 🧪 Examples

```bash
ip a
ping google.com
ss -tuln
nslookup google.com
curl https://example.com
wget https://example.com/file.zip
```
